<h1 style="font-family: 'Segoe UI', sans-serif; font-weight: 700; font-size: 2.5em; margin-bottom: 0.5em;">Stone Paper Scissors Game</h1>

<p>An interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript. This web-based application offers a fun and engaging way to play the classic hand game against a computer with real-time results and dynamic animations.</p>

<h2 style="font-family: 'Segoe UI', sans-serif; font-weight: 600; font-size: 1.8em; border-bottom: 2px solid #ccc; padding-bottom: 0.2em; margin-top: 1em;">Features</h2>
<ul>
  <li><strong>Real-Time Gameplay:</strong> Play against a computer that randomly selects its moves.</li>
  <li><strong>Dynamic UI:</strong> Smooth animations and visual feedback for each move.</li>
  <li><strong>Responsive Design:</strong> Fully optimized for desktops, tablets, and mobile devices.</li>
  <li><strong>Score Tracking:</strong> Keeps track of player and computer scores throughout the session.</li>
</ul>

<h2 style="font-family: 'Segoe UI', sans-serif; font-weight: 600; font-size: 1.8em; border-bottom: 2px solid #ccc; padding-bottom: 0.2em; margin-top: 1em;">Technologies Used</h2>
<ul>
  <li><strong>HTML:</strong> Provides the structure of the game.</li>
  <li><strong>CSS:</strong> Enhances the visual appeal with animations and styling.</li>
  <li><strong>JavaScript:</strong> Implements the game logic and user interactions.</li>
</ul>
